# Block Notification — спокойный интернет без навязчивых запросов

[![Privacy first](https://img.shields.io/badge/Privacy-local%20only-2ea44f)](https://chromewebstore.google.com/detail/block-notification/djljbdlfbneldoedlmdhmgnjhomfkoja?authuser=2&hl=ru)

## [Установить Block Notification в Chrome Web Store →](https://chromewebstore.google.com/detail/block-notification/djljbdlfbneldoedlmdhmgnjhomfkoja?authuser=2&hl=ru)

**Block Notification** — лёгкое расширение для Google Chrome, которое блокирует всплывающие запросы сайтов на отправку уведомлений. Читайте, работайте и покупайте без бесконечных «Разрешить уведомления?».

### Меньше шума. Больше контроля.

- Блокирует запросы на уведомления до того, как они отвлекут вас.
- Нужный сайт можно добавить в исключения одним нажатием.
- Список разрешённых сайтов легко изменить в любой момент.
- Без аккаунта, рекламы, аналитики и передачи данных.
- Настройки хранятся только локально в вашем браузере.

> Расширение блокирует **новые запросы разрешения**. Оно не отменяет уведомления сайтов, которым вы уже разрешили их отправлять.

## Как пользоваться

1. [Установите Block Notification из Chrome Web Store](https://chromewebstore.google.com/detail/block-notification/djljbdlfbneldoedlmdhmgnjhomfkoja?authuser=2&hl=ru).
2. Оставьте расширение включённым — новые запросы сайтов будут заблокированы.
3. Если уведомления от конкретного сайта нужны, откройте иконку расширения и разрешите их для этого сайта.
