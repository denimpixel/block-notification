# Block Notification

### A calmer web starts here.

Block Notification is a lightweight Chrome extension that stops intrusive website notification permission prompts before they interrupt you. Keep browsing focused, then allow notifications only from the websites you choose.

## Silence notification prompts. Keep control.

The web is full of “Allow notifications?” pop-ups. Block Notification handles them before they disrupt your reading, work, shopping, or research.

- **Block notification prompts by default.** Turn it on once and browse without interruptions.
- **Allow the sites that matter.** Add the current website to your allow list directly from the extension popup.
- **Stay in control.** Remove an allowed website whenever you want.
- **See protection at a glance.** A clear switch and `ON` badge show when blocking is active.
- **Private by design.** No accounts, ads, analytics, remote code, or network requests.

> Block Notification prevents future notification permission prompts. It does not revoke notification access already granted to a website.

## How it works

1. Click the Chrome button above to install Block Notification.
2. Leave the extension enabled to block notification permission prompts across the web.
3. When a website is worth hearing from, open the extension popup and select **Allow notifications on this site**.

## Privacy

Your preferences stay in Chrome's local extension storage on your device. Block Notification stores only its on/off status and the websites you explicitly allow. It does not collect, sell, transmit, or share personal data.
